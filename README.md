# 背单词

本地网页背词工具。在页面里选择自己的 Anki 牌组（`.apkg`），内容只在当前浏览器解析和保存，不会上传。

```bash
npm install
npm run dev
```

打开终端显示的地址，选择牌组即可。

快捷键：`R` 听发音，`空格` 显示答案，`1-4` 评分，`←` `→` 翻词，`Esc` 关闭。

学习进度保存在当前浏览器。换浏览器或清理站点数据前，请先在设置里导出进度。

## 多设备使用

牌组不在这个仓库里。每台设备第一次打开网页时，选择一次自己的 `.apkg`，内容只保存在该设备的浏览器中。

学习进度不会自动同步，可以在设置里导出，再到另一台设备恢复。手机上建议把网页添加到主屏幕。
