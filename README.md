# 背单词

无敌绿宝书 N1 背词网页：https://weilong-lab.github.io/jp-word-book/

打开就能用。词表、词条和牌组音频来自公开仓库 [jp-word-book-deck](https://github.com/weilong-lab/jp-word-book-deck)，第一次使用时加载，并留在设备上。

```bash
npm install
npm run dev
```

快捷键：`空格` 翻面，翻面后再按一次算认识；`D` 不认识；`R` 听发音；`F` 已熟悉；`S` 生词本；`Z` 撤销；`←` `→` 翻词；`Esc` 关闭。

## 学习进度

默认保存在当前浏览器。换设备或清理站点数据前，在设置里导出进度，到新设备上恢复。

连接访问令牌的设备会把进度同步到私有仓库，也能使用私有的神经语音和例句音频。令牌只保存在该设备的浏览器中。

手机和 iPad 上建议用分享菜单的“添加到主屏幕”，之后像 App 一样全屏打开，没有网络时也能打开。主屏幕上的 App 和浏览器的数据分开保存。
