# 背单词

本地网页背词工具。在页面里选择自己的 Anki 牌组（`.apkg`），内容只在当前浏览器解析和保存，不会上传。

```bash
npm install
npm run dev
```

打开终端显示的地址，选择牌组即可。

快捷键：`R` 听发音，`空格` 显示答案，`1` 不认识，`2` 认识，`←` `→` 翻词，`Esc` 关闭。

没有连接私有仓库时，学习进度只保存在当前浏览器。换浏览器或清理站点数据前，请先在设置里导出进度。

## 多设备使用

牌组不在这个仓库里。词表和音频放在私有仓库，每台设备第一次打开网页时填一次 GitHub 访问令牌，令牌只保存在该设备的浏览器中。

连接后词表立即可用，音频在第一次播放时加载并留在设备上，学习进度自动同步到私有仓库。也可以选择本机 `.apkg`，这时内容只保存在当前浏览器。手机上建议把网页添加到主屏幕。
